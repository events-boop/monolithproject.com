# Chasing Sun(Sets) II — House of Friends Launch

## Event Frame

- **Date:** Saturday, August 22, 2026
- **Venue:** Castaways Beach Club, Chicago
- **Host event:** Chasing Sun(Sets) II
- **House of Friends role:** Featured artist-development and community program within the day
- **Planned headliner:** Enoo Napa, 8:00 PM–10:00 PM

## Recommended Working Schedule

This version uses six pre-headliner performance blocks and protects ten minutes between each block.

| Time              | Programming                           | Working purpose                          |
| ----------------- | ------------------------------------- | ---------------------------------------- |
| 11:00 AM–12:15 PM | House of Friends Collaborative Set 01 | Arrival and discovery                    |
| 12:25 PM–1:40 PM  | Collaborative Set 02                  | Community pairing                        |
| 1:50 PM–3:05 PM   | Collaborative Set 03                  | Build the room                           |
| 3:15 PM–4:30 PM   | Collaborative Set 04                  | Experienced and emerging artist exchange |
| 4:40 PM–6:10 PM   | House of Friends Founding Class B3B   | Featured filmed performance              |
| 6:20 PM–7:50 PM   | Monolith Resident / Sunset Builder    | Golden-hour handoff                      |
| 7:50 PM–8:00 PM   | Headliner changeover                  | Protected technical reset                |
| 8:00 PM–10:00 PM  | Enoo Napa                             | Headline performance                     |

## Public Narrative

**Discovery → Collaboration → Founding Class → Sunset → Enoo Napa**

House of Friends owns the collaborative daytime story. The Founding Class is the featured payoff rather than the first opener, giving the selected artists a stronger crowd, better atmosphere, and meaningful placement without asking them to carry the direct-support slot.

## Production Requirements

### Stage and Audio

- Standardize the DJ setup and USB workflow.
- Confirm whether transitions are musical handoffs or hard resets.
- Schedule a pre-open line check and a Founding Class recording check.
- Capture direct master audio for every recorded set.
- Maintain an emergency playback source.

### Artist Operations

- Artist call time at least 60 minutes before each set.
- USB and Rekordbox verification before stage standby.
- Named stage manager and artist liaison.
- Written B2B/B3B handoff rules.
- Credentials, hospitality, and green-room plan.

### Content

- Three-camera coverage for the Founding Class.
- Defined coverage level for all other sets.
- Professional photography and vertical social capture.
- Artist interview window away from stage noise.
- Standard intro, lower-third, thumbnail, and end-card system.

### Partner Integration

- Welcome and program signage.
- Artist gifting and equipment presentation plan.
- Partner wall or modular activation footprint.
- QR destinations with campaign attribution.
- Sponsor content capture list approved before event day.

## Contingency Questions

- Weather and partial closure plan.
- Camera positions permitted by the venue.
- Drone permissions or prohibition.
- Audio recording approval and isolation quality.
- Headliner technical and branding restrictions.
- Response if a collaborative artist cancels.
